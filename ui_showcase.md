# Демонстрация работы интерфейса и основные фичи

В данном документе представлены скриншоты работы веб-приложения с кратким описанием каждого этапа и технологий, используемых под капотом.

## 1. Авторизация и профиль пользователя

### Авторизация (Часть 1)
![Авторизация 1](docs/images/Авторизация_1.jpg)
*Экран входа в систему. Реализовано с использованием HTML/CSS на фронтенде и FastAPI для безопасной обработки аутентификации на бекенде.*

### Авторизация (Часть 2)
![Авторизация 2](docs/images/Авторизация_2.jpg)
*Ввод учетных данных и успешный вход. В основе может лежать JWT-авторизация или сессионные cookie для поддержания состояния пользователя.*

### Настройки профиля
![Настройки профиля](docs/images/Настройки_профиля.jpg)
*Управление настройками пользователя. Используется чистый Frontend (JS/CSS) для отображения UI и FastAPI для сохранения пользовательских предпочтений в БД.*

## 2. Главный экран и темы оформления

### Главный экран (Светлая тема)
![Главный экран (светлая тема)](docs/images/Главный_экран_светлая_тема.jpg)
*Основной рабочий интерфейс чата в светлой теме. Для динамического обновления интерфейса без перезагрузки страниц применяется HTMX (или Vanilla JS).*

### Главный экран (Темная тема)
![Главный экран (темная тема)](docs/images/Главный_экран_темная_тема.jpg)
*Поддержка темной темы. Смена темы происходит средствами CSS-переменных и сохраняется в LocalStorage или настройках профиля.*

---

## 3. Взаимодействие с AI-помощником

### Возможность записи голоса
![Возможность записи голоса](docs/images/Возможность_записи_голоса.jpg)
*Использование Web Speech API или внешнего сервиса распознавания речи (STT) для перевода голоса в текст прямо в браузере.*

### Запрос про "Мостик"
![Запрос про "Мостик"](docs/images/Запрос_про_Мостик.jpg)
*Пользователь задает вопрос. На этом этапе срабатывает Router-агент (GigaChat Lite), извлекая параметры (например, продукт P702 - Мостик).*

### Поиск информации про "Мостик"
![Поиск информации про "Мостик"](docs/images/Поиск_информации_про_Мостик.jpg)
*Гибридный поиск в действии. Под капотом работает LanceDB (Векторный поиск) + BM25, а также RRF (Reciprocal Rank Fusion) и Cross-Encoder для отбора топ-кандидатов.*

### Формирование ответа по "Мостику"
![Формирование ответа по "Мостику"](docs/images/Формирование_ответа_по_Мостику.jpg)
*Сбор контекста. В работу вступает Answer-агент (GigaChat Max), формируя точный ответ на базе найденных документов.*

### Ответ по "Мостику"
![Ответ по "Мостику"](docs/images/Ответ_по_Мостику.jpg)
*Итоговый ответ агента с цитатами `[slug]`. Рендерится через Markdown-парсер на стороне клиента.*

## 4. Визуализация и работа с документами (Вложения)

### Граф связей по "Мостику"
![Граф связей по "Мостику"](docs/images/Граф_связей_по_Мостику.jpg)
*Интерактивный граф источников (Pyvis / NetworkX), визуализирующий связи между документами и вопросом. Отражается вес (score) из Cross-Encoder.*

### Вложение по "Мостику"
![Вложение по "Мостику"](docs/images/Вложение_по_Мостику.jpg)
*Отображение вложений к ответу. Реализовано через систему Attachments Parser, которая извлекает метаданные и отдает файлы через FastAPI.*

### Документ регламента по "Мостику"
![Документ регламента по "Мостику"](docs/images/Документ_регламента_по_Мостику.jpg)
*Просмотр самого документа (например, PDF, DOCX или MD) непосредственно в интерфейсе или по клику из ответа.*

---

## 5. Дополнительные возможности и фичи

### Распознанный текст (Голос/OCR)
![Распознанный текст](docs/images/Распознанный_текст.jpg)
*Текст, полученный из OCR (например, для картинок) или после транскрибации.*

### Ответ по распознанному текста
![Ответ по распознанному тексту](docs/images/Ответ_по_распознанному_тексту.jpg)
*GigaChat обрабатывает извлеченный текст и отвечает на вопрос по контенту изображения или транскрипта.*

### Добавление пользователем файла и работа с ним
![Добавление пользователем файла и работа с ним](docs/images/Добавление_пользователем_файла_и_работа_с_ним.jpg)
*Загрузка файлов "на лету" (Upload Files). Под капотом FastAPI принимает файл, парсер извлекает текст, эмбеддер векторизует и кладет во временный индекс.*

### Ответ по пользовательскому файлу
![Ответ по пользовательскому файлу](docs/images/Ответ_по_пользовательскому_файлу.jpg)
*Анализ загруженного документа (RAG on-the-fly). GigaChat Max использует содержимое пользовательского файла в качестве контекста.*

### Добавление чата в избранное, удаление чата
![Добавление чата в избранное, удаление чата](docs/images/Добавление_чата_в_избранное_удаление_чата.jpg)
*История сессий и закладок. Управление стейтом чатов (CRUD-операции) через API, сохранение состояния в БД (например, SQLite/PostgreSQL).*
