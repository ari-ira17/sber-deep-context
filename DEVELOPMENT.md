# Руководство разработчика (Developer Guide)

Добро пожаловать в проект **SBER Deep Context**! Данный документ предназначен для новых разработчиков, желающих разобраться в архитектуре, добавить новые фичи или агентов, а также понять, как работает существующий RAG-пайплайн.

## Архитектура приложения

Проект использует микросервисную архитектуру агентов (Deep Agents) и FastAPI для пользовательского интерфейса.

### 1. Пользовательский интерфейс (UI)
- **Технологии:** FastAPI (веб-фреймворк), HTMX (реактивность без сложных JS-фреймворков), Vanilla JS, HTML/CSS.
- **Точка входа:** `app/main.py`.
- **Шаблоны:** Находятся в `app/templates/`. Главный шаблон чата — `chat.html`.
- **Голосовой ввод:** Интегрирован Web Speech API (распознавание речи прямо в браузере).
- **Стриминг:** Ответы от языковой модели передаются по SSE (Server-Sent Events) в реальном времени.

### 2. Агентный Пайплайн (Agents Pipeline)
Чтобы не превышать лимиты GigaChat API (1 поток), мы используем ровно два LLM-вызова для каждого запроса:

1. **Router Agent (`agents/router_agent.py`):**
   - Использует быструю модель (GigaChat Lite).
   - Задача: проанализировать запрос, вытащить `product_code`, `slug`, флаг `need_attachment` и переформулировать запрос для поиска.
2. **Search / Retrieval (`rag/`):**
   - Получает структурированный запрос от роутера.
   - Выполняет поиск (Metadata-First, векторный, BM25) и реранкинг (Cross-Encoder).
   - *Особенность:* Для запросов вида "список всех продуктов", система автоматически перехватывает интент и подставляет полный справочник в начало, игнорируя лимиты `top-k`.
3. **Answer Agent (`agents/answer_agent.py`):**
   - Использует самую мощную модель (GigaChat Max).
   - Задача: сгенерировать точный, лаконичный ответ на основе найденных `DocumentContext`.
   - Подставляет ссылки на источники в формате `[slug]`.
   - Имеет сложную систему форматирования (списки для каталогов кода, и строгий один абзац для логических ответов).

Оркестрацией всего пайплайна занимается класс `MeridianOrchestrator` в `agents/orchestrator.py`.

### 3. Model Context Protocol (MCP) Сервер
Мы поддерживаем интеграцию через MCP для экспорта ответов.
- **Точка входа:** `mcp/server.py`.
- Используется библиотека `FastMCP`.
- Позволяет внешним IDE или системам запрашивать экспорт документов (Markdown, DOCX).

## Как добавить новую функциональность

### Добавление нового Агента
1. Создайте файл `agents/my_new_agent.py`.
2. Создайте класс агента, который будет принимать `GigaChatClient`.
3. Напишите Pydantic-модель для структурированного вывода (Output).
4. Зарегистрируйте агента в `agents/pipeline.py` через `create_deep_agent`.

### Изменение логики RAG (Поиска)
1. Основная точка входа RAG — `rag/search.py` (и резервный класс `StandaloneSearchEngine` в `agents/orchestrator.py`).
2. Если вам нужно изменить веса гибридного поиска, смотрите `rag/rrf.py` (Reciprocal Rank Fusion).
3. Чтобы добавить новые метаданные в поиск, обновите класс `DocumentContext` в `agents/answer_agent.py` и `agents/orchestrator.py`.

### Добавление фронтенд-фич
1. Редактируйте шаблоны в `app/templates/`.
2. Если фича требует запросов к бэкенду без перезагрузки, используйте атрибуты HTMX (например, `hx-post="/my-endpoint"`).
3. Роуты FastAPI регистрируются в `app/main.py`.

## Запуск с нуля (Автозагрузка данных)

При клонировании репозитория векторная база данных (`data/lancedb/`) изначально пуста.
- Хотя при первом старте часть данных загрузится автоматически, **строго рекомендуется** запустить скрипт инжеста. Он загрузит данные из `data/dataset_with_vectors.json`, создаст скалярные индексы и **полнотекстовый FTS-индекс (BM25)**:
  ```bash
  python scripts/ingest.py
  ```
- **ВАЖНО:** Для корректной работы с вложениями (изображения, PDF, исходный код) убедитесь, что папка `meridian_hackathon_knowledge_base` находится в **корне проекта**. Если ее там нет, скачайте и поместите ее в корень (на одном уровне с `app`, `rag` и `README.md`).

Для повседневной разработки и запуска рекомендуется использовать Docker:
```bash
docker-compose up --build
```

## Тестирование и отладка

- **Unit и интеграционные тесты:** `pytest tests/test_agents.py`
- **Калибровочный скрипт (Бенчмарк):** `python scripts/run_calibration.py`. Этот скрипт прогоняет 100 сложных вопросов (из `calibration_questions.json`) через Router и проверяет правильность извлечения метаданных. Всегда запускайте его после изменения `router_agent.py`.

## Полезные советы
- Следите за логами FastAPI (`uvicorn`) — там пишутся все тайминги и результаты работы Router Agent.
- При редактировании системных промптов (в `agents/prompts/`), помните о строгих правилах (anti-hallucination). Лучше добавлять примеры (few-shot), чем усложнять словесные инструкции.
- Для генерации презентаций проекта используйте `python generate_overview_pdf.py` (генерирует PDF с помощью `fpdf`).
